# 실험 결과

`2026-10-28_16-50-18.540_KST`는 공개된 10×10 데이터셋으로 실행한 GPT-6.1 Sol 100문제의 결과입니다. MPE는 38.80%이며 실제 채점 제출은 2,734개입니다.

| 파일·폴더 | 내용 |
|---|---|
| `calls/` | API 응답 원문, 요청 식별자, 토큰 사용량·시간·비용 |
| `requests/` | 키와 인증 헤더를 제외한 요청 본문 |
| `attempts.jsonl`, `attempts.csv` | 제출 배치·실제 경로·정오답·지속적 오류 판정 |
| `rounds.json/csv`, `problems.json/csv` | 라운드·문제별 집계 |
| `summary.json`, `RESULTS.html` | 전체 요약 및 열람 화면 |
| `api-usage-cost.csv` | 요청별 토큰 사용량·추정 비용 |
| `transcripts/` | 문제별 대화 기록 |
| `code-snapshot/` | 결과 재생성과 검증에 사용하는 Python 실행·채점 코드 |
| `config.json` | 실험 설정, 스냅샷 해시, 결과 기록 정보 |
| `*-snapshot.*` | 실험 데이터·프롬프트·가격표 |

응답의 암호화된 추론 항목은 원본 응답과 후속 요청의 동일성을 검증하는 데 사용합니다. 이를 모델이 어떤 추론을 했는지 읽을 수 있는 공개 사고 과정으로 해석하지 않습니다.

저장된 API 응답으로 Python 채점기를 실행해 시도별 판정과 결과 보고서를 생성합니다. `verify_results.py`는 API를 호출하지 않고 요청·응답 해시, 판정, 집계를 검증합니다. 실제 요청·응답과 토큰 사용량·비용·시간은 실험 기록 그대로 유지합니다.

새 실험은 날짜·시간별 별도 폴더에 저장됩니다. 기본 `.gitignore`는 새 실행 결과를 제외하므로 공개할 결과를 검토한 뒤 명시적으로 추가해야 합니다.
